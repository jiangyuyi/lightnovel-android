# 阅读顶部信息与简繁转换

## 实现范围

- 在分页与滚动共用的阅读布局顶部显示书名、章节，各占一行信息栏的一半；长标题省略，点击可查看完整名称。
- 保留系统状态栏，通过 `WindowInsets.safeDrawing` 获取顶部和横向安全区，不硬编码刘海高度。信息栏参与布局测量，正文与之不重叠，菜单仍然覆盖正文。
- 设置提供原文、简体、繁体，默认原文；保存在 DataStore，兼容已有设置。暂不映射到网站只有布尔含义的 `traditional_chinese` 设置，单独更改此选项不请求服务器。

## 成熟库选型

使用 [opencc4j](https://github.com/houbb/opencc4j) `1.14.0`，通过 Maven Central / 现有阿里云镜像引入。使用库提供的 `ZhConverterUtil.toSimple` 和 `toTraditional`，支持词组转换，不自行维护映射表或实现转换算法。不额外引入可选 jieba 分词依赖，不使用 JNI，不上传正文。

`ReaderChineseConverter` 仅处理已解析的显示模型，保留块数量、顺序、段落缩进和插图尺寸。转换标题、段落及链接标签，链接目标与插图地址不变；纯网址标签也原样保留。每次转换都基于源章节，不基于上一次转换结果，缓存不受影响。自动转换并不等同人工校对，有歧义时可切回原文。

## 性能与阅读进度

- 使用 `Dispatchers.Default` 在后台转换；切换设置/章节时取消旧任务，块之间检查取消，避免迟到结果覆盖新章节。
- 切换时保留现有页面，结果准备完毕后整体替换、重新排版；不发起正文网络请求。
- 当前章节按块索引保留阅读位置；因字形/长度变化可能定位至当前段落所在页，不保证页码或行位置完全一致。
- 分页数量缩小时不通过隐藏的尾页触发自动切章，章节末尾继续向前翻仍可正常进入下一章。
- 原文无需初始化转换词库，设置弹窗支持滚动。
