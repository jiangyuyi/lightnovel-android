# 页面导航动效

## 1.8.2（2026-11-10）

动效统一配置在 `MainActivity` 的 `NavHost`，由 `core/ui/PageMotion.kt` 决定类型、`PageTransitions.kt` 提供 Compose 过渡。使用现有 Navigation Compose 2.8.5 和 Compose BOM，不引入动画库、不更换依赖版本。

| 场景 | 过渡 |
| --- | --- |
| 发现 / 书架 / 搜索 / 我的之间 | 180 ms 淡入淡出，不暗示页面深度 |
| 进入子页面 | 240 ms 淡入，向左移动进入；初始偏移为容器宽度的 1/10 |
| 从子页面返回 | 240 ms 反向淡入/滑动 |
| 进出阅读页、同路由不同内容 | 180 ms 淡入淡出，不对正文增加横向位移 |
| 无起始或目标路由 | 不增加过渡 |
| 重复点击当前底部标签 | 不触发导航或重新播放动画 |

出场页面只移动容器宽度的 1/20，避免整屏长距离运动。动效使用 Compose 原生有限时长动画，遵循系统动画缩放；不增加独立计时器，不为等待网络人为延长转场。

## 边界与回归

- 保持原有导航栈、`saveState` / `restoreState`、ViewModel 和缓存策略；动画不触发额外刷新。
- 不改变阅读分页、正文翻页手势、点击热区、字体、状态栏与安全区域计算。
- 不为筛选条件切换、后台刷新或每次重组播放全屏导航动画；弹窗和底部面板沿用 Material 现有行为。
- `PageMotionTest` 覆盖全部底部页面组合、各类子页面进退、阅读页进出和空/相同路由。新增顶层导航时同步维护 `PageMotion.kt` 的顶层路由集合。
- 本地验证运行单元测试、Lint、签名 Release 构建并检查证书和版本。真机检查建议：四个底部入口连点、书籍详情进退、消息/私信进退、阅读页进退、系统动画关闭后操作，确认位置/返回栈/阅读进度保持不变。

参考：[Android 官方 Compose 动画指南](https://developer.android.com/develop/ui/compose/animation/quick-guide)。
