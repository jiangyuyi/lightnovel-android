# 官方福利中心调查与签到接入

## 范围（2026-09-26）

真机页面包括七日签到、浏览时长、浏览作品、收藏作品、通知奖励、邀请好友、睡觉任务，以及文书申请和勇者答题入口。当前账号今日签到已经领取，因此不能通过重复领取验证一次新的奖励到账。

## 接口证据

从用户手机的官方安装包中只读检查得到接口路径；未提取官方 App 私有数据、账号令牌或签名密钥。安装包和调查截图只保存在被 Git 忽略的 `artifacts/official-coins/`，不分发官方代码或资源。

匿名 POST 实测确认现有 `https://www.lightnovel.fun/api/pc-proxy/` 能访问：

| 路径 | 用途与状态 |
| --- | --- |
| `api/bff/welfare-home-v1` | 返回 wallet、sign_in、earn_coin、tasks；匿名为 guest |
| `api/bff/welfare-sign-detail-v1` | 返回签到模块；匿名已验证 |
| `api/bff/claim-welfare-sign-v1` | 官方安装包中的签到领取路径；接入后需登录真机验证 |
| `api/bff/welfare-coin-records-v1` | 轻币记录；匿名返回业务码 8，本轮不接入 |

签到读取 home 的 `wallet.coin/today_coin` 和 `sign_in`，沿用本 App 的 `security_key`。不硬编码奖励金额、签到周期或活动键。只在 enabled、claimable 为真且 claimed 为假时允许手动领取；领取请求只传现有登录凭据，不自动签到，不自动重试写请求。

## 实施及验证计划

1. “我的”增加签到入口，轻币余额数字也可打开签到详情。
2. 展示服务器下发的奖励日列表、领取状态、余额和今日收益。
3. 领取后重新查询状态；网络超时也先查询，避免误判失败后重复领取。无法核实时禁用领取，要求刷新。
4. 退出详情刷新个人余额，清理领取前的个人概览缓存；每次打开及回到前台刷新签到状态，避免跨天沿用旧资格。
5. 补充解析与领取状态机测试，构建、检查并保留数据覆盖安装，核对官方 App 和本 App 的状态一致性。
6. 当前账号今日已领，只能验证已领状态；首次实际发奖需另一天由用户点击签到完成验收，不修改设备时间或伪造签到日期。

## 后续任务边界

浏览任务必须基于真实阅读及服务器规则；通知奖励涉及实际通知权限与服务接入；邀请好友涉及分享和其他用户。暂不复制这些流程，不伪造心跳、广告完成或任务进度。安装包还包含 sleep、treasure-box、earn-coin 和 task 的细分接口，仅路径存在不能证明当前账号有资格或功能已开放。
