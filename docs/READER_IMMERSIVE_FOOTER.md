# 沉浸式阅读与底部信息栏

## 布局

参考用户提供的多看截图，隐藏阅读界面的系统状态栏和导航栏，沿用顶部书名/章节。正文仍避让系统报告的刘海与打孔安全区。边缘滑动可以临时唤出系统栏，返回前台重新进入沉浸模式，退出阅读恢复系统栏。

底栏左侧为电量图标、百分比（充电时加号）及系统格式时间，右侧为本章当前页 / 总页数。页码与现有阅读器保持相同统计范围，不是整本书总页数；滚动模式按段显示。

使用“同时内缩和上移”布局：左右至少 28dp，底部至少 20dp；Android 12 起读取两侧底部圆角半径，左右内缩不少于较大半径加 4dp；旧设备使用基础边距。底部同时考虑 safeDrawing 安全区。底栏独立参与 Column 高度测量，分页正文只使用剩余区域，不采用覆盖正文的浮层。

电量通过系统粘性电池广播初始化并更新；时间响应分钟、手动改时及时区变化，返回前台立即刷新，遵循系统 12/24 小时格式。后台停止广播监听，离开页面释放监听。

实现依据：[Android 沉浸模式](https://developer.android.com/develop/ui/views/layout/immersive)、[圆角避让](https://developer.android.com/develop/ui/views/layout/insets/rounded-corners)、[Compose 安全区](https://developer.android.com/develop/ui/compose/system/insets)。
