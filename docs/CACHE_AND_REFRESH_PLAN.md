# 1.3.0 缓存与稳定刷新实施计划

## 1. 目标

1. 页面再次进入时优先展示已有内容，不再清空为全屏转圈。
2. 缓存过期或用户手动刷新时保留当前内容，在后台请求成功后原位替换。
3. 冷启动时从磁盘恢复主要列表、详情、目录和正文；完全没有缓存时使用稳定骨架占位。
4. 网络失败时保留缓存内容并显示非阻塞错误，不把可用页面替换成错误页。
5. 缓存与登录用户隔离，不存储密码、验证码或 `security_key`。

## 2. 数据流

采用 stale-while-revalidate：

```text
页面进入
  ├─ 有新鲜缓存：立即展示，不发起重复请求
  ├─ 有过期缓存：立即展示 + 后台刷新
  │                    ├─ 成功：原位替换并更新时间
  │                    └─ 失败：保留旧内容并提示
  └─ 无缓存：显示骨架 + 请求服务器
                       ├─ 成功：展示并写入缓存
                       └─ 失败：显示全页错误与重试
```

手动刷新始终请求服务器，但刷新期间继续展示已有内容。

## 3. 两级缓存

### 3.1 内存层

- 进程内 `ConcurrentHashMap`，保存最近读取的数据和时间戳。
- 同一页面往返时避免磁盘反序列化和重复网络请求。
- 登录变更时清除所有用户作用域内存项。

### 3.2 磁盘层

- 使用 Android 内置 `SQLiteOpenHelper`，不新增 Room/KSP 构建依赖。
- 数据模型使用项目现有 Kotlin Serialization 转为 JSON。
- 表字段包含缓存键、作用域、JSON、保存时间、最后访问时间和字节数。
- 总上限 96 MiB；写入后按最后访问时间淘汰最旧记录。
- 数据库 schema 和缓存键带版本号；模型不兼容时丢弃单项缓存，不影响 App 启动。

## 4. 作用域与隐私

- `public`：发现、排行、搜索分类、公开书籍、卷、章、评论。
- `user:{uid}`：书架、个人资料、关注/粉丝、阅读记录、发布管理、未读汇总。
- 私信会话、私信正文和通知正文仅放内存，不写磁盘。
- 章节正文允许写入磁盘，并纳入 96 MiB 统一 LRU 淘汰。
- 退出登录时删除全部 `user:*` 磁盘和内存缓存；公开内容与正文保留。
- 缓存键只包含公开参数和 UID，不包含会话令牌。
- `content_cache.db` 排除在 Android 云备份和设备迁移之外，正文缓存不离开当前设备。

## 5. 默认时效

| 数据 | TTL | 磁盘 |
| --- | ---: | --- |
| 发现、排行、新书、分区 | 5 分钟 | 是 |
| 搜索分类 | 24 小时 | 是 |
| 搜索结果 | 5 分钟 | 是 |
| 书籍详情、卷、章节目录、评论 | 30 分钟 | 是 |
| 章节正文 | 7 天 | 是 |
| 书架、阅读记录 | 1 分钟 | 是，按 UID |
| 个人资料、关注、粉丝、发布管理 | 2 分钟 | 是，按 UID |
| 消息未读、通知、私信 | 30 秒 | 仅内存 |

## 6. 页面状态

页面状态统一区分：

- `loading`：无任何内容的首次加载，显示骨架。
- `refreshing`：保留内容并显示顶部细进度条。
- `error`：无内容时的阻塞错误。
- `refreshError`：有内容时的非阻塞刷新错误。
- `lastUpdatedAt`：成功缓存或网络更新时间。

页面自动进入使用 `refresh(force = false)`；用户点击刷新使用 `force = true`。

## 7. 失效与一致性

- 加入/移出书架：失效书架、书籍详情和阅读入口状态缓存。
- 关注/取消关注：失效关注、粉丝和个人资料缓存。
- 删除阅读记录、保存阅读进度：失效阅读记录；正文缓存不删除。
- 标为已读：失效消息未读和对应分类内存缓存。
- 登录成功：切换到新 UID 作用域。
- 退出登录：清空全部用户私有缓存。

## 8. 实施范围

1. 通用缓存存储、策略、缓存事件和测试替身。
2. 发现、搜索、书架、书籍详情、目录、评论与正文。
3. 个人资料、关注/粉丝、阅读记录、发布管理。
4. 消息未读、通知和私信的短时内存缓存。
5. 页面骨架、顶部后台刷新指示和保留内容的错误提示。
6. 版本升级到 `1.3.0` / `versionCode 6`，更新 README 和 Changelog。

## 9. 验收

- 单元测试覆盖 TTL、新鲜/过期缓存、缓存优先事件、网络失败保留、LRU 决策和作用域清除。
- `testDebugUnitTest`、`lintDebug`、`assembleDebug`、签名 `assembleRelease` 通过。
- 真机验证：底部页面往返无全屏转圈，详情返回稳定；手动/后台刷新保留旧内容；进程重启从磁盘恢复。
- 真机验证正文：在线读过章节后，停止网络访问时仍可打开缓存章节。
- 登录私有数据不跨 UID；退出登录后个人缓存不可恢复。

## 10. 实施结果

- 两级缓存、TTL、96 MiB LRU、缓存键版本、用户作用域、退出清理和写操作失效均已实现。
- 主要列表、详情、账户页、消息页与章节正文已迁移为缓存优先更新流；消息和私信保持仅内存缓存。
- 首次无缓存使用骨架，有内容刷新使用顶部进度条和非阻塞错误；主要页面提供显式刷新入口。
- 单元测试、Lint、Debug/签名 Release 构建通过。
- 小米 Android 16 真机完成覆盖安装、登录态保留、进程重启、完全断网首页恢复和 27 页正文离线阅读验证。
